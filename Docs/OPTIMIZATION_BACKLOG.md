# 产品优化清单

## 阶段边界

当前阶段冻结新增音乐应用适配，只优化汽水音乐、Apple Music、网易云音乐和灵动岛基础体验。QQ 音乐、Spotify 等新适配，计时器、通知和 Windows 版本不进入本轮开发。

## P0 - 日常使用稳定性

| 状态 | 优化项 | 负责人 | 验收指标 |
| --- | --- | --- | --- |
| 已验收 | 合并高频鼠标移动事件并启用 Release 日常安装 | 开发工程师 / QA | 事件每 8ms 最多投递一次最新位置；Release 安装完成；实机悬停响应 60ms；见 `acceptance/2026-07-19-p0-hover-performance.md` |
| 部分完成 | 展开、收回和内容切换帧节奏 | UI/UX / 开发工程师 | 已消除窗口中间帧 1pt 水平漂移并通过单窗口脚本；下一步审计内容动画和反向操作录屏 |
| 待开始 | 主线程阻塞审计 | macOS 架构师 / QA | 元数据、封面、AX 和诊断读取不阻塞动画；日常空闲 CPU 建立固定基线 |
| 待开始 | 三个现有音乐来源状态一致性 | macOS 架构师 / QA | 切歌、播放暂停、退出和来源切换不显示旧状态；控制只发往当前已选应用 |
| 待开始 | 状态流生命周期和进程回收 | 开发工程师 / QA | 主 App 退出后无残留流进程；来源重启不重复创建监听进程 |

## 统一质量门禁

每个优化项必须通过 `swift test`、Release 构建和对应的实机回归。涉及窗口或动画的改动还必须通过单窗口锚定脚本，并记录优化前后数据；没有量化或实机证据的项目不能标记为完成。
