## 为什么要重排

- 对外版本仍是 **v0.1.3-alpha.2 / build 180（2026-10-14）**，已经一个月。main 上是 build 188，多了：协调器拆分第 1–3 步（行为不变）、纯黑表面与新主题层、展开音乐“沉浸”面板、悬停收起修复。
- 原计划的“v0.1.3 收尾、不加功能”已经被事实越过：新面板就是功能。继续把这些改动压在 0.1.3 里，版本号就说不清楚。
- v0.1.3 收尾剩下的两件事（重录 README 演示、发布）放在新面板定型之后做，演示只需录一次。
- v0.2.0 的门禁里，除了重放夹具和拆分前三步，其余都没开始，6–10 周的估计需要按里程碑拆开，才看得出卡在哪里。

## 风险

| 风险 | 应对 |
| --- | --- |
| Apple Developer Program 审核拖延 | M2 开始就申请；若 M4 时仍未通过，v0.2.0 先以 ad-hoc 发 beta，正式版顺延 |

| 界面反复改版消耗时间 | 展开音乐冻结；其他状态的改动先出 1:1 示意稿再写代码 |
| CI 偶发失败掩盖真实问题 | 测试里不用固定时长等待；失败当天修复 |
