## 定位

顶屿是 MacBook 刘海上的音乐岛：把正在听的歌——歌名、封面、进度、歌词和只会命中该播放器的三枚按钮——放在视线最上方；计时和日程提醒只在需要时短暂借用这块位置。

本规划期内不做：AI Command Bar（1.0 之后再议）、系统 HUD 与通知镜像、浏览器或 PWA 播放器适配，以及任何需要放宽项目安全规则的能力。

## 近期：v0.1.3 收尾（约 1–2 周，不加功能）

- 歌词结果分类埋点：只记分类，不记歌名歌词，为后台歌词问题取证。
- 用当前 build 重录 README 演示。
- 文档收口与 CI 补两条检查：Python 脚本测试、验收索引是否过期。
- `main.swift` 文件级拆分，仅搬运，不改行为。
- 建立 `GATES_v0.1.3.md`。阶段退出时开放项只剩“后台歌词”，且已有取证数据。

## 中期：v0.2.0 稳定日用版（约 6–10 周）

主题是可信赖，不是新功能：

- 状态流重放夹具入 CI，作为重构的安全网。
- 拆分音乐协调器，汽水改为统一 `MusicAppAdapter` 实现；引入“已发布曲目令牌”，统一异步结果的身份校验，门槛不降。
- 切歌等待期的“切换中”反馈（先取证早期候选误报率），控制不可用的四种原因分开呈现，设置诊断页显示媒体键归属。
- 首次使用引导：先选播放器，只申请该播放器需要的权限。
- 辅助功能通读：旁白、增强对比度、降低透明度，复验减少动态效果下的歌词。
- 后台歌词按取证数据给出明确结论；网易云、Apple Music 补齐样本后由 Alpha 升 Beta；日历与提醒事项实机验收。
- 加入 Apple Developer Program，v0.2.0 起只发布 Developer ID 签名并公证的安装包。
- 冻结 QQ 音乐、Spotify 等新播放器适配，直到 v0.2.0 发布。

阶段退出：`GATES_v0.2.0.md` 全绿或逐项书面豁免，从 Release 页下载的安装包完成发布后验收。

进度见 [GATES_v0.2.0](acceptance/GATES_v0.2.0.md)。2026-11-14：状态流重放夹具（五类序列）已入库并随 CI 运行；协调器拆分第 1 步（匿名使用诊断抽成 `MusicUsageEmitter`）完成，行为不变。

不做例行长时间测试：以日常使用为准，出现问题再修复（2026-11-13 负责人决定）。

## 远期：v0.3 及以后

- 二选一，不并行：第四个播放器（倾向 QQ 音乐）或文件暂存区。v0.2.0 退出时再定。
- 有 Developer ID 后引入自动更新。
- 英文界面与更多机型像素验收。
- 汽水定向 seek 与无窗口控制继续标为上游受阻，只在汽水提供公开接口时重启。
- AI Command Bar 在 1.0 之后再议。
