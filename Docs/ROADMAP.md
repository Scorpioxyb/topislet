# 路线图

## 当前版本：v0.1.3-dev 日常体验可观测性

目标：把音乐岛做成可真实使用的本机 App，而不是视觉 Demo。

已完成：

- SwiftUI + AppKit 顶部浮层。
- 折叠、紧凑、展开三种状态。
- 汽水音乐 MediaRemote Adapter 常驻流同步。
- 封面补齐、可信进度、受保护点击 / 拖动跳转和播放控制回读。
- 汽水唯一语义 AX 播放控制，不切换前台 App、不移动鼠标、不发送全局媒体键。
- Apple Music PID 定向 Alpha 支持、自动来源选择和绝对进度控制。
- 网易云音乐 PID 定向 Alpha 支持、专属状态流、原子切歌门控和原生语义控制。
- 三来源自动选择：前台适配应用立即切换，后台按汽水、网易云音乐、Apple Music 的真实播放优先级选择。
- 设置面板、布局校准、本地打包安装。
- QuickPlayer/QuickTime 媒体焦点冲突保护。
- 展开音乐面板使用统一网格：92pt 封面，标题、时间轴和控制轨道共享视觉中轴，窗口模式按钮独立避让。
- 三态窗口、主体遮罩和内容使用同一形变时间轴；控制按钮只保留一次即时按压反馈，进度拖动点仅在悬停或操作时显示。
- 专辑色进度轨按纯黑背景校正感知亮度：暗色可辨、亮色不过曝、灰阶保持中性，并消除切歌封面稍晚到达时的白色闪烁。
- seek 终态区分确认、超时和正常取消；日报可识别连续拖动覆盖、切歌、来源切换、播放器退出和 App 停止，不再把正常合并误判为日志缺口。

## 当前开发：v0.1.3 日常体验优化

目标：不增加音乐应用、计时器和通知范围，利用真实日常日志优先修复现有音乐同步和交互问题。

计划：

- 补齐 seek 确认、超时和取消的完整终态覆盖与取消原因统计。
- 以日常日志中的控制、切歌文本、封面和 seek P50/P95 为下一轮优化依据。
- 对真实越线指标做小范围修复，保持来源定向、安全门禁和隐私边界不变。
- 继续以 GitHub ad-hoc 签名 DMG 发布；开发阶段不创建 Tag、不推送 Release。

详细范围和指标见 `Docs/V0.1.3_PLAN.md`。

## 后续版本：v0.2.0 稳定性与体验优化

目标：暂停扩大应用范围，把现有汽水音乐、Apple Music、网易云音乐和灵动岛交互打磨为稳定的日常试用版本。

计划：

- 跑完 `Docs/MVP_ACCEPTANCE.md` 的 P0 验收。
- 优先处理 `Docs/OPTIMIZATION_BACKLOG.md` 的 P0 性能与状态一致性项目。
- 降低鼠标悬停、展开收回和内容更新对主线程的压力。
- 完成汽水在抖音、QuickTime 和浏览器并存场景的 P0 回归。
- 继续验证 Apple Music Alpha 支持的封面、并发控制、权限恢复和多账号环境，达到稳定门槛后再升级支持等级；歌词仍单独排期。
- 扩大网易云音乐 Alpha 的同专辑切歌、电台、退出回退、抖音并存和多设备样本，达到稳定门槛后再升级支持等级。
- 完善设置、权限恢复、多显示器切换和长时间运行质量门禁。
- 形成手工验收视频清单，并把问题记录到 `Docs/ISSUE_BOARD.md`。

本阶段明确冻结 QQ 音乐、Spotify 和其他新音乐应用适配，也不扩展计时器与通知；完成稳定性门禁后再重新评估。

## v0.3.0 音乐能力增强

目标：补齐歌词和更稳定的专辑信息。

计划：

- 优化歌词来源优先级：MediaRemote、AX 可见歌词、汽水本地共享状态研究。
- 封面缓存策略升级，避免切歌时封面明显慢一拍。
- 稳定汽水语义 AX 控件识别，并继续研究不会误控系统当前媒体的汽水专属 seek。

## v1.0.0 扩展能力

目标：从音乐岛扩展为 MacBook 顶部轻操作中心。

候选：

- 会议麦克风/摄像头状态。
- 专注计时器。
- 系统提醒聚合。
- 下载/上传进度。
- 快捷操作与键盘触发。
