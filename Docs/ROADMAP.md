## 定位

顶屿是 MacBook 刘海上的音乐岛：把正在听的歌——歌名、封面、进度、歌词和只会命中该播放器的三枚按钮——放在视线最上方；计时和日程提醒只在需要时短暂借用这块位置。

本规划期内不做：AI Command Bar（1.0 之后再议）、系统 HUD 与通知镜像、浏览器或 PWA 播放器适配，以及任何需要放宽项目安全规则的能力。

按 [版本计划](product/VERSION_PLAN_2026-11.md)（2026-11-15 确认）：不加功能，把 main 上已完成的发出去——CI 全绿、一轮汽水专属控制与新面板短实机、重录 README 演示、按发布检查清单发布。原“v0.1.3 收尾”由这一版接替，后台歌词取证转入 v0.2.0。

## 中期：v0.2.0 稳定日用版（约 8 周，2027-01 中旬）

主题是可信赖，不是新功能，分四个里程碑：

- M1 后端收口（到 12-06）：协调器拆分第 4 步，汽水实现 `MusicAppAdapter` 并引入已发布曲目令牌；后台歌词按数据给出结论；早期候选误报率取证。
- M2 状态与反馈（到 12-20）：控制不可用四态与媒体键路由提示、切歌过渡、折叠与紧凑新布局、计时 / 通知 / 活动中心统一表面。
- M3 上手与可及（到 01-03）：首次使用引导、辅助功能通读、网易云与 Apple Music 升 Beta、日历与提醒事项验收。
- M4 发布（01-10 前后）：Developer ID 签名并公证（负责人在 M2 期间加入 Apple Developer Program）、门禁收尾、发布后验收。

冻结新播放器适配直到 v0.2.0 发布；展开音乐构图在 v0.1.4 后冻结，只修问题。阶段退出：`GATES_v0.2.0.md` 全绿或逐项书面豁免，从 Release 页下载的安装包完成发布后验收。

进度见 [GATES_v0.2.0](acceptance/GATES_v0.2.0.md)。2026-11-14：状态流重放夹具（五类序列）已入库并随 CI 运行；协调器拆分第 1 步（匿名使用诊断抽成 `MusicUsageEmitter`）、第 2 步（播放操作跟踪抽成 `PlaybackOperationTracker`）与第 3 步（进度跳转抽成 `SeekCoordinator`，2026-11-15）完成，行为不变。前端视觉有了新提案（[前端设计新方案](design/FRONTEND_REDESIGN_2026-11.md)），表面选定纯黑方向 A；主题层（D0）与新令牌数值（D1 部分）已在代码中完成，待实机验收；展开音乐三行布局（D2）装机试用后因歌词占比太少被否决；2026-11-15 第二轮选定“沉浸”方向（build 187–188：大封面 + 单栏歌词、封面模糊铺底、控制行悬停出现）。

不做例行长时间测试：以日常使用为准，出现问题再修复（2026-11-13 负责人决定）。

## 远期：v0.3 及以后

- 二选一，不并行：第四个播放器（倾向 QQ 音乐）或文件暂存区。v0.2.0 退出时再定。
- 有 Developer ID 后引入自动更新。
- 英文界面与更多机型像素验收。
- 汽水定向 seek 与无窗口控制继续标为上游受阻，只在汽水提供公开接口时重启。
- AI Command Bar 在 1.0 之后再议。
