# 路线图

## 当前版本：V1.5 本机原型

目标：把音乐岛做成可真实使用的本机 App，而不是视觉 Demo。

已完成：

- SwiftUI + AppKit 顶部浮层。
- 折叠、紧凑、展开三种状态。
- 汽水音乐 MediaRemote Adapter 常驻流同步。
- 封面补齐、进度拖动、播放控制回读。
- 设置面板、布局校准、本地打包安装。
- QuickPlayer/QuickTime 媒体焦点冲突保护。

## 下一版本：V1.6 体验稳定性

目标：减少卡顿和状态跳变，让连续点击、切歌、展开收起接近原生手感。

计划：

- 统一状态机：把 UI 展开状态、媒体控制状态、外部点击收起做成明确的状态转移。
- 动效审计：降低多层 SwiftUI 动画叠加，保留单一主动画曲线。
- 汽水同步抖动控制：歌名、歌手、封面作为一个原子批次更新。
- 增加同步延迟日志，仅在设置/诊断中显示。
- 形成手工验收视频清单。

## V1.7 音乐能力增强

目标：补齐歌词和更稳定的专辑信息。

计划：

- 优化歌词来源优先级：MediaRemote、AX 可见歌词、汽水本地共享状态研究。
- 封面缓存策略升级，避免切歌时封面明显慢一拍。
- 研究汽水定向控制能力，在安全边界内替代系统媒体键。

## V2 扩展能力

目标：从音乐岛扩展为 MacBook 顶部轻操作中心。

候选：

- 会议麦克风/摄像头状态。
- 专注计时器。
- 系统提醒聚合。
- 下载/上传进度。
- 快捷操作与键盘触发。
