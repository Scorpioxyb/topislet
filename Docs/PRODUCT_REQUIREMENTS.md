# MacBook 灵动岛产品需求文档

## 产品定位

MacBook 灵动岛是在 MacBook 摄像头模组周围建立的顶部活动承载区。汽水音乐是当前默认主活动；计时器、提醒和后续完成适配的应用按事件临时接管，不提供固定功能标签。

## V1 核心目标

- 视觉上贴近 Apple Dynamic Island：黑色胶囊、克制动效、无调试文案、与摄像头模组对齐。
- 第一优先场景是汽水音乐：真实歌名、歌手、封面、播放态、进度和基础控制。
- 普通提醒短暂覆盖后恢复汽水最新状态；用户展开、拖动或执行媒体控制时不得被自动事件打断。
- 不使用假数据冒充真实同步；不可读时只在设置和诊断中说明原因。
- 同时播放视频时，不能让 QuickPlayer/QuickTime 等播放器把汽水音乐岛清空，也不能误把控制命令发送给视频播放器。
- 提供设置面板、布局校准、打包后的本地 App 入口。

## 目标用户

- 个人 MacBook 用户，尤其是长期听歌、写代码、学习、开会的人。
- 对视觉细节敏感，希望 macOS 顶部区域更精致、更有用的人。
- 愿意接受本机原型权限配置，但不希望开启高成本 OCR 或屏幕录制方案。

## 范围

### P0

- 顶部摄像头区域胶囊常驻显示。
- 汽水音乐真实同步：歌名、歌手、封面、播放/暂停、进度、拖动跳转。
- QuickPlayer/QuickTime 抢占系统媒体会话时，保留最近一次可信汽水状态，并阻止误控其他播放器。
- 点击外部自动收起展开态。
- 设置面板与布局校准。
- 岛内不显示音乐、计时器、提醒三个固定入口。
- 计时器只在用户启动后出现；普通提醒自动恢复到之前的有效活动。
- 本地可安装 `.app` 包。

### P1

- 歌词显示质量提升。
- 更接近原生 Dynamic Island 的状态切换动画。
- 多显示器/不同 MacBook 刘海尺寸适配。
- 更明确的同步来源诊断面板。

### P2

- 为更多媒体、会议和消息应用分别开发适配器。
- 日历、提醒事项和已授权应用事件接入；不承诺统一读取全部 macOS 通知。
- 汽水专属定向 seek 与公开安全接口研究。

## 非目标

- 不注入或修改汽水音乐 App。
- 不做网络抓包、token 提取或 MITM。
- 不使用 OCR 作为主同步链路。
- 不把 macOS 控制中心当作后台自动同步来源。
