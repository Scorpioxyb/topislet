# 顶屿 TopIslet v0.1.1-alpha.3

本版本继续作为 GitHub Alpha 开发者预览版发布，在保持汽水音乐为主适配的基础上，加入 Apple Music Alpha 支持。

## 主要变化

- 播放与暂停点击立即反馈，真实汽水状态在后台确认，失败时安全回滚。
- 修复启动、展开和切歌时旧时间样本覆盖新样本的问题。
- 修复暂停后进度继续前进、回退或被 AX 旧进度覆盖的问题。
- QuickTime 占用系统媒体焦点的实机回归证明，非公开 MediaRemote client 命令即使报告“已派发”，仍可能暂停当前视频而不是汽水；顶屿已停止把该通道用于产品按钮和诊断入口。
- 播放、暂停、上一首和下一首只允许触发汽水 PID 内经过结构校验的唯一语义 AX 控件，不发送全局媒体键、不切换前台 App，也不移动鼠标。
- 修复汽水重启后 Electron 控件树未初始化导致按钮无反应：顶屿在控制前开启 `AXManualAccessibility`，再执行唯一语义控件校验；初始化不激活汽水、不切换前台 App。
- 辅助功能权限现为汽水音乐控制的必要条件；音乐状态与进度仍由汽水专属 MediaRemote 流读取。
- Apple Music 可通过定向 Apple Event 读取歌曲、播放状态和进度，并支持播放 / 暂停、切歌和绝对进度跳转；需要用户授权“自动化 - Apple Music”。
- Apple Music 当前歌曲的真实专辑封面会按曲目身份读取并缓存；切歌期间的迟到封面会被拒绝，封面不可用时不影响其他播放功能。
- Apple Music 电台未提供内嵌封面时，顶屿会在后台通过 Apple 公共目录执行唯一精确匹配；封面查询和下载不会阻塞歌名、播放状态或控制反馈。
- 电台会话的下一首可直接利用 `playerInfo` 歌名、歌手和专辑提前预取目录封面，待 PID 定向快照确认曲目身份后再显示；普通歌曲的元数据和原生封面改为单次读取。
- 修复快速切歌时旧请求误清除新封面刷新信号的问题，并移除封面数据到达后的额外淡入等待，缩短歌名与封面之间的可见时间差。
- 原生歌曲在 `playerInfo` 到达后立即预取封面，并以 PID、完整曲目 ID 和最终快照三重确认后显示；上一首 / 下一首不再额外并发发送第二次重型封面读取。
- 各封面读取路径增加双向去重和目录失败退避；Apple 目录区域查询超时时不再紧接着等待第二次全局超时。
- Apple Music 播放 / 暂停改为点击即刻更新本地状态，随后由绑定 PID 与曲目身份的定向 Apple Event 确认；连续点击保持串行顺序，旧失败结果不会回滚新操作。
- Apple Music 稳态同步改为 `playerInfo` 通知优先；播放中、暂停和后台仅保留 5 / 10 / 15 秒兜底读取，并合并重复通知，避免无变化时持续请求 Music 电台或商店状态。
- 前台切到汽水或 Apple Music 时岛立即跟随当前应用；离开两个音乐应用后按真实播放状态自动选择，其他未适配媒体不会参与路由。
- 播放、切歌和进度操作绑定点击瞬间岛实际显示的应用；目标进程或曲目失效时安全取消，不会改投另一款音乐应用。另移除本机验收用的分布式媒体控制通知。
- 应用切换先更新岛的来源身份，再异步读取歌曲与封面；控制执行期间切到另一应用时，迟到结果不会覆盖新的岛内容。
- 音乐设置页现在区分“主适配”“Alpha 支持”和实际运行状态，自动显示汽水辅助功能、Apple Music 自动化权限、连接响应与最近同步状态。
- Apple Music 适配可在设置中关闭；关闭后不再参与来源选择、轮询、封面查询或定向控制，重新启用后恢复自动切换。
- Apple Music 连接检查复用岛当前使用的同一个适配器，不再创建第二个诊断实例；应用退出、PID 变化或权限失效时会清空旧连接和歌曲状态。
- Apple Music 读取和控制绑定适配生命周期代次；关闭、撤权或快速重开后，迟到读取不能写回缓存或重新启动封面任务，已排队但尚未执行的控制会被拒绝。
- 设置连接检查等待协调器现有的单飞刷新并只显示已接受快照；实时歌曲和进度统一放在“当前活动”，不再与静态连接结果重复显示。
- 汽水和 Apple Music 都没有真实当前歌曲时，默认胶囊不再因鼠标经过而展开空面板；暂停歌曲、计时器和有效提醒仍可悬停展开。
- 空状态首次接收到汽水或 Apple Music 的真实歌曲后，默认胶囊会自动切换成带封面的紧凑音乐岛；普通状态刷新不会反复强制展开。
- Apple Music 暂停和后台状态不再因低频轮询而被误判为来源失效，专辑封面岛会稳定保持到应用退出或明确无歌曲。
- 汽水 MediaRemote stream 在应用退出、停止或异常重启时会取消旧重启任务并回收对应子进程；旧回调无法重新写入状态，命令行 SIGINT / SIGTERM 也不会留下后台订阅进程。
- 汽水播放 / 暂停产生的新临时媒体 UUID 不再被误判为切歌，同一首歌的歌手、专辑、时长和封面保持稳定。
- 汽水重启后的旧 PID 迟到事件会被拒绝；缺少稳定元数据的同名稀疏事件只更新播放时间轴，不改变歌曲身份或刷新播放证据。
- 汽水完全退出后媒体身份校验会关闭数据入口；缺少 PID 的完整 payload 只从唯一运行实例补全，多实例时拒绝。PID 切换和同名稀疏新曲会重置旧时间轴，避免重新显示已退出进程的歌曲或继承上一首进度。
- 异步歌手、专辑与封面补取绑定请求会话和 PID；汽水重启期间旧实例返回的同名元数据不会覆盖当前歌曲。
- 汽水辅助功能树运行中失活时，顶屿会在安全失败路径重建 `AXManualAccessibility` 并有界重扫；不会激活汽水或使用坐标点击。
- 冷启动和屏幕布局刷新期间会在动画结束后校准窗口最终位置与尺寸，避免封面状态已就绪但窗口仍停在空胶囊外形。

## 验证

- 105 项自动化回归测试通过；新增连续 10 首原子切歌压力序列、未适配视频前台隔离、快速播放暂停策略、单窗口中心/顶边、透明肩部交互区、透明画布动画所有权、动画代次和最小化窗口恢复回归。
- 顶部胶囊与展开主体合并为单一 `NSPanel`，保留 8pt 视觉间隔，并统一悬停、外部点击和最终 frame 所有权。
- CI 现在执行全部测试；Release workflow 增加精确 tag、干净工作区和测试门禁，DMG 验证增加版本号与构建号一致性检查。
- 汽水窗口最小化导致 Electron AX 树不完整时，顶屿只对唯一标准窗口做后台临时恢复，执行定向控制后立即恢复最小化；不会激活汽水或移动鼠标。
- 独立抖音 App 前台播放实测通过：视频进度连续前进，汽水暂停/恢复、下一首和上一首均未改变抖音前台与播放状态。
- Chrome 带声音视频成为系统媒体焦点时，汽水专属同步和三种控制实测通过；Chrome 始终播放、保持前台，鼠标位置不变。
- Safari 带声音视频成为系统媒体焦点时，汽水专属同步和三种控制实测通过；Safari 始终播放、保持前台，鼠标位置不变。
- MediaRemote Adapter 从固定上游 commit 与项目补丁逐字节重建通过。
- 汽水窗口与顶屿并行采样的播放进度误差约 1 秒。
- 暂停后两端进度保持冻结；恢复播放与切歌状态一致。
- 安装包内不再包含 Python 控制脚本。

## 已知限制

- 汽水音乐是当前产品级主适配；Apple Music 为 Alpha 支持，普通歌曲和可唯一匹配的电台曲目已支持专辑封面，暂不提供歌词。
- 汽水页面没有形成唯一安全语义控件时，三个播放控制会拒绝操作；不会回退到系统当前媒体。
- 项目依赖 macOS 非公开 MediaRemote 能力，系统更新后需要重新验证。
- 汽水进度条当前只读；系统全局跳转和会误控其他媒体的私有 player-path 跳转均未接入产品。
- 本包为 ad-hoc 签名、未公证的 Alpha 预览版，首次打开可能出现 Gatekeeper 提示。
- 计时器和通知不属于本阶段优先范围。

## 安装

打开 `TopIslet-v0.1.1-arm64.dmg`，将“顶屿.app”拖到“Applications”快捷入口。

校验下载文件：

```bash
shasum -a 256 -c TopIslet-v0.1.1-arm64.dmg.sha256
```
