# 顶屿 TopIslet v0.1.1-alpha.3

本版本继续作为 GitHub Alpha 开发者预览版发布，在保持汽水音乐为主适配的基础上，新增 Apple Music 实验适配。

## 主要变化

- 播放与暂停点击立即反馈，真实汽水状态在后台确认，失败时安全回滚。
- 修复启动、展开和切歌时旧时间样本覆盖新样本的问题。
- 修复暂停后进度继续前进、回退或被 AX 旧进度覆盖的问题。
- QuickTime 占用系统媒体焦点的实机回归证明，非公开 MediaRemote client 命令即使报告“已派发”，仍可能暂停当前视频而不是汽水；顶屿已停止把该通道用于产品按钮和诊断入口。
- 播放、暂停、上一首和下一首只允许触发汽水 PID 内经过结构校验的唯一语义 AX 控件，不发送全局媒体键、不切换前台 App，也不移动鼠标。
- 修复汽水重启后 Electron 控件树未初始化导致按钮无反应：顶屿在控制前开启 `AXManualAccessibility`，再执行唯一语义控件校验；初始化不激活汽水、不切换前台 App。
- 辅助功能权限现为汽水音乐控制的必要条件；音乐状态与进度仍由汽水专属 MediaRemote 流读取。
- Apple Music 可通过定向 Apple Event 读取歌曲、播放状态和进度，并支持播放 / 暂停、切歌和绝对进度跳转；需要用户授权“自动化 - Apple Music”。
- Apple Music 当前歌曲的真实专辑封面会按曲目身份读取并缓存；切歌期间的迟到封面会被拒绝，封面不可用时不影响其他播放功能。
- Apple Music 电台未提供内嵌封面时，顶屿会在后台通过 Apple 公共目录执行唯一精确匹配；封面查询和下载不会阻塞歌名、播放状态或控制反馈。
- Apple Music 播放 / 暂停改为点击即刻更新本地状态，随后由绑定 PID 与曲目身份的定向 Apple Event 确认；连续点击保持串行顺序，旧失败结果不会回滚新操作。
- 前台切到汽水或 Apple Music 时岛立即跟随当前应用；离开两个音乐应用后按真实播放状态自动选择，其他未适配媒体不会参与路由。
- 播放、切歌和进度操作绑定点击瞬间岛实际显示的应用；目标进程或曲目失效时安全取消，不会改投另一款音乐应用。另移除本机验收用的分布式媒体控制通知。
- 应用切换先更新岛的来源身份，再异步读取歌曲与封面；控制执行期间切到另一应用时，迟到结果不会覆盖新的岛内容。

## 验证

- 70 项自动化回归测试通过，覆盖权威时间轴、stream 差分、旧样本拒绝、连续操作、前台应用路由、显示来源控制绑定、跨来源进度保护、来源切换、缓存状态让位、播放证据新鲜度、切歌门控隔离、Apple Music PID 绑定、电台封面精确匹配、Apple HTTPS 主机白名单、封面失败退避与异步封面时间轴保护。
- MediaRemote Adapter 从固定上游 commit 与项目补丁逐字节重建通过。
- 汽水窗口与顶屿并行采样的播放进度误差约 1 秒。
- 暂停后两端进度保持冻结；恢复播放与切歌状态一致。
- 安装包内不再包含 Python 控制脚本。

## 已知限制

- 汽水音乐是当前产品级主适配；Apple Music 仍是实验适配，普通歌曲和可唯一匹配的电台曲目已支持专辑封面，暂不提供歌词。
- 汽水页面没有形成唯一安全语义控件时，三个播放控制会拒绝操作；不会回退到系统当前媒体。
- 项目依赖 macOS 非公开 MediaRemote 能力，系统更新后需要重新验证。
- 本包为 ad-hoc 签名、未公证的 Alpha 预览版，首次打开可能出现 Gatekeeper 提示。
- 计时器和通知不属于本阶段优先范围。

## 安装

打开 `TopIslet-v0.1.1-arm64.dmg`，将“顶屿.app”拖到“Applications”快捷入口。

校验下载文件：

```bash
shasum -a 256 -c TopIslet-v0.1.1-arm64.dmg.sha256
```
