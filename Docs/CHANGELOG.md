# 变更记录

## Unreleased

- 重排展开音乐面板的纵向结构：窗口模式按钮改为右上角悬浮层，不再独占 24pt 工具栏行；音乐内容使用完整 126pt 内高，标题与歌手区域为按钮保留 72pt 安全距离，底部媒体控制获得至少 12pt 留白。计时器和提醒继续沿用原有工具栏布局。
- 展开音乐面板的专辑封面放大至 88pt，封面与详情组合调整为 408pt；三枚媒体按钮改为与 224pt 进度轨共用中心线，消除控制区偏右。封面右下角根据歌曲来源 bundle identifier 显示 18pt 真实音乐 App 圆角方形角标，轻微跨出封面边缘；未知来源安全降级，紧凑态不显示徽标。
- 简化上一首 / 下一首点击反馈：移除图标方向位移和旋转等待环，固定圆形按钮只做短促亮度与 0.96 按压缩放；连续切歌仍保留独立操作代次与 520ms 安全窗口，旧命令失败、超时或较早元数据回包不会影响最新操作，并尊重“减少动态效果”。
- 统一展开 / 收回动效时间轴：Header 几何只由 AppKit 窗口驱动，Body 几何只由 SwiftUI 遮罩驱动，禁用系统窗口默认缩放；移除独立 sleep 与末尾强制 snap，改用真实动画 completion，并将 Header、Body 内容改为可反向交叉淡化；同值活动发布不再重复启动窗口动画或短暂禁用展开态按钮。
- 新增正式 macOS App 图标：以 MacBook 摄像头刘海和三色状态波形构成深色圆角方块，并随安装包写入 `IslandAppIcon.icns`；核心符号针对 32px 小尺寸单独强化。
- 顶部 Header 改为贴屏的单一纯黑轮廓，移除重复刘海 Shape、描边与半透明边缘；整块 Header 统一点击命中，左侧封面区域也可正常展开。
- 新增低打扰悬浮交互：鼠标进入顶部岛 160ms 后自动展开，Header、8pt 间距和 Body 视为连续悬浮区域，移出 350ms 后恢复进入前形态；快速进出会取消过期任务，点击展开仍保持固定展开。
- 紧凑态移除播放 / 暂停图标，右侧统一为真实歌曲进度和专辑色三条波形；底部中央鼠标光圈确认为 Codex Computer Use 测试覆盖层，不属于 App 渲染。
- 收回顶部胶囊默认摄像头高度补偿 1pt，并让最终高度落在完整像素边界，减少摄像头模组下方多余黑边和透明底线；三条状态波形改为 Core Animation 播放动效，并从当前歌曲真实封面后台提取安全化专辑色，暂停或减少动态效果时保持静止。
- 恢复顶部 Header 与展开 Body 之间的 8pt 分隔，并将顶部可见黑色外壳、AppKit 窗口 frame 和 Body Shape 在同一模式切换周期内连续插值；展开和收回不再以宽度硬跳开始。
- 修复展开 / 收回瞬间横向偏移：禁用灵动岛 `NSHostingView` 按 SwiftUI 内容自动改写窗口尺寸，按目标模式同步插值 frame，并取消过期的连续点击重排任务；顶部窗口切换尺寸时始终保持屏幕中线不变。
- 重做展开 / 收回动效：取消整个 Body 窗口的透明度动画，改为纯黑 Shape 从顶部锚点展开和收缩；内容独立淡入淡出并由同一形变遮罩裁切，消除灰色闪块、空黑大面板和隐藏窗口吞点击。
- 修复展开态默认左偏：动画结束后按当前尺寸重新吸附屏幕中线，避免顶部窄岛残留切换前横坐标；音乐与计时器内容列及控制组改为明确居中。
- 新增 EventKit 日程事件源：用户可在设置的“日程”页分别授权日历和提醒事项；临近 10 分钟的定时日程、刚到期 5 分钟内的定时提醒进入已有低打扰事件队列，默认忽略全天日程和无具体时间的提醒。
- EventKit 读取采用后台快照查询，并通过设置代次和最终权限复核阻止关闭功能或撤权后的旧结果回灌；日历与提醒事项独立授权、独立降级，不影响汽水主活动。
- EventKit 事件按具体事项身份去重和取消，不同事项不会因来源相同而错误合并；最多保留 48 小时、512 条本地投递记录。
- 新增 `--eventkit-status` 只读权限诊断，不主动请求系统权限。
- 灵动岛改为单一主活动：正常启动默认显示汽水音乐，移除展开页的音乐 / 计时器 / 提醒固定标签以及设置中的默认功能选择。
- 新增本机 `IslandEvent` 入口和事件队列：普通事件短暂覆盖后恢复汽水，高优先级事件不会被普通消息覆盖，拖动、seek 和媒体控制确认期间不抢占用户交互。
- 普通事件只合并同一来源；不同应用来源分别排队。事件期间用户主动改变展开形态时，恢复内容但保留用户最新选择的形态。
- 媒体状态读取改为汽水专属客户端流：MediaRemote Adapter 使用 `stream-client com.soda.music` 持续订阅，并用 `get-client com.soda.music` 定向补取，不再让抖音、QuickTime 等系统当前媒体源决定岛内内容。
- 新增汽水 MediaRemote client 定向控制：系统解释器承载的轻量桥直接查找 `com.soda.music` client 并发送播放 / 暂停、上一首、下一首；实测不切换前台 App、不移动鼠标，也不跟随抖音等系统当前媒体源。
- 保留语义化 AX 安全降级：只绑定汽水 PID，并根据角色、结构和相邻控件特征选择唯一目标；client 通道与唯一 AX 控件都不可用时安全失败。
- 移除“实用模式 / 严格模式”、短暂激活汽水和全局媒体键运行路径。
- MediaRemote Adapter framework 更新为 `arm64` + `x86_64` Universal 二进制。
- 切歌元数据改为暂存后原子发布：新歌名出现但歌手或封面仍属于旧曲时，继续保留上一完整画面，待元数据一致后统一提交。
- client 控制、播放回读和 AX 降级扫描均移出主线程；控制点击立即显示按压反馈，等待环延迟 120ms 出现，上一首和下一首拥有独立 pending 状态。
- 模式点击冷却从 720ms 缩短到 80ms，控制后的模式抑制从 280ms 缩短到 60ms，改善连续点击响应。
- 收窄折叠、紧凑和展开尺寸；展开上下窗口以 3pt 重叠形成连续黑色轮廓，统一黑度、描边、圆角，并压缩计时器和提醒布局。
- 状态绿点改为白色微型波形，避免与 macOS 摄像头隐私指示灯混淆。
- 优化进度条单击跳转：单击与拖动使用独立手势，点击不再触发圆点缩放脉冲；单击采用更短的 seek 合并窗口，并保持即时本地预览和最终操作优先。
- 优化进度条拖动手感：拖动预览与时间标签同步，seek 和常规播放位置回读移出主线程，连续 seek 串行执行并带超时；命令确认前保持目标位置，避免松手卡顿和旧进度回弹。
- 修复播放/暂停后的时间回退：控制命令使用带操作代次和时间锚点的乐观播放状态，MediaRemote 仅用命令后的新样本确认，缓存样本只负责显示；暂停进度单调稳定，连续快速点击基于上一次目标状态反转。
- 设置面板显示固定的“汽水 client 定向控制”策略，并可隐藏 / 显示音乐诊断信息。
- 音乐诊断模式新增 UI progress、elapsed、duration、canSeek、pending、封面字节数，并支持一键复制诊断信息。
- 优化切歌元数据稳定性：封面补齐回包必须匹配当前曲目，封面视图按曲目与封面身份刷新，减少旧封面残留。
- 修复音乐进度识别：AX 兜底不再把汽水窗口中的列表/旧歌时间误当成当前播放进度；主界面进度只使用 MediaRemote Adapter 的可信 elapsed/duration。
- 媒体焦点被其他播放器抢占时继续使用汽水客户端专属流，避免用其他 App 的 Now Playing 覆盖汽水状态。
- 修复点击/展开灵动岛时进度条视觉上从 0 重新开始的问题：非拖动状态下进度条禁用隐式宽度动画，直接显示当前可信进度。
- 修复点击岛时进度被 fallback 状态刷回 0 的问题：切换折叠/展开前先刷新当前可信播放状态，并阻止无 `elapsedTime/duration` 的 AX/placeholder 状态覆盖已有 MediaRemote 进度。
- 修复点击岛后进度显示成开头几秒的问题：折叠/展开前改为同步刷新一次 MediaRemote Adapter 播放位置，并在播放中每约 2 秒校准一次真实 elapsed/duration。
- 优化汽水 AX 监听：不再每 2 秒强制重扫可访问性树，减少观察节点和通知类型，降低同步抖动与后台开销。
- 进度跳转在不能确认汽水为可跳转目标时保持阻断，避免 seek 误控视频播放器；汽水专属定向 seek 仍是后续底层任务。
- 修复抖音/Chrome 视频页并行时主 App 高 CPU、灵动岛点击无响应的问题：常规 UI tick 不再同步拉取 MediaRemote/AX，音乐状态发布改为事件驱动加低频进度刷新。
- 启动时不再自动打开设置窗口；设置/校准窗口关闭后释放 SwiftUI 内容，避免隐藏窗口继续重排拖慢灵动岛。
- 修复布局校准自触发循环：屏幕信息未变化时不再重复发布 `currentDisplayName`、`notchWidth` 和 `topBandHeight`，主 App 稳态 CPU 恢复到低占用。
- 新增产品需求文档、路线图、QA 检查清单。
- Git 忽略第三方 App 解包产生的本地 JavaScript 调查文件，避免把专有产物纳入产品仓库。
