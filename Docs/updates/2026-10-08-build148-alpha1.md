# v0.1.3-alpha.1 · build 148

2026-10-08。开发者预览，不是稳定版。

## 这次改变了什么

- 汽水暂停时点击进度条，跳到目标位置后播放，不再被顶屿自动暂停。已经播放或状态不明确时不盲切；切歌、切换来源和后续手动控制会使旧操作失效。此次修复针对汽水路径，Apple Music 控制路径未改变。
- 无歌词时显示低强调的“聆听音乐”。只有歌词内容明确说明纯音乐时，才显示“纯音乐，请欣赏”；没有读到歌词不等于纯音乐。
- 保留浅银灰底板墨镜 Logo，以及歌词时间轴、逐字高亮、切歌缓存和重复副歌高亮等开发预览功能。

## CI 异步测试修复

此前测试以 80 毫秒固定延迟模拟旧歌曲 B 的元数据补读。在 CI 调度较慢时，B 可能已经结束，测试才注入新歌曲 C，偏离了原本需要验证的竞态。

两条竞态测试均改为明确的同步门闩：B 开始读取 → 注入 C 或完整状态流 → 放行 B → 等待处理完成。旧候选让位测试等待 C 的歌名、歌手、专辑、封面完整发布；完整状态流优先测试等待迟到任务实际结束后，再检查样本编号未增加。新增只在 Debug 中编译的只读任务观察入口，Release 不包含该入口。不调整运行时媒体读取逻辑，不跳过测试。

旧测试以零读取延迟复现相同的四个失败断言；修复后焦点测试与完整 325 项 Swift 测试通过。10 项 Python 打包工具测试、控制安全检查通过。远程 CI 状态以对应提交的 GitHub Actions 记录为准。

## 实机证据与边界

build 148 签名安装后，先确认汽水稳定暂停在 2:06，点击进度条跳至 1:36，随后约 16 秒后进度达到 1:52 且仍播放，没有再次自动暂停。此轮实机验收覆盖点击路径；拖动共用跳转逻辑，未在此轮单独做鼠标拖动验收。

歌词显示默认关闭；开启歌词查询会发送歌名和歌手用于匹配，不上传账号或播放历史。第三方歌词覆盖和上游状态时序仍可能影响歌词可用性及延迟，不承诺所有歌曲都能逐字高亮。

## 下载与安装

[v0.1.3-alpha.1](https://github.com/Scorpioxyb/topislet/releases/tag/v0.1.3-alpha.1) 提供 arm64 DMG 和 SHA-256 校验文件。要求 Apple Silicon、macOS 26.0 或更新版本，不提供 Intel 安装包。

安装包仅 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证。系统可能提示开发者无法验证，请先判断是否信任本项目；不要关闭 Gatekeeper 或系统安全保护。安装时将顶屿拖到 Applications，媒体控制需要按需授权辅助功能；Apple Music 另需自动化权限。
