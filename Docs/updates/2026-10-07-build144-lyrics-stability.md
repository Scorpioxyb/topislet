# build 144：歌词与切歌稳定性更新

顶屿源码开发预览更新到 0.1.3 build 144。本次同步开发代码，不发布新的可下载 Release；公开下载仍为 v0.1.1-alpha.4。README 的视频与截图来自 build 137，继续作为布局和交互示意。

## 本次行为

- 展开音乐面板集中左侧封面、歌曲信息和播放控制，为右侧歌词、长句滚动和进度条提供空间；可选择紧凑歌词和展开策略。
- 可选汽水词级时间轴会核验歌名、完整歌手名单与时长，按播放位置更新句子与逐字高亮。不能确定的版本不猜测歌词。
- 会话内最多缓存 24 首成功核验的歌词，切回同歌同版本时复用；首次空结果 3 秒后重试，随后有界退避到 30 秒。关闭功能清空缓存，不保存到磁盘。
- 统一系统播放身份，避免多歌手的逗号/斜线显示差异反复取消请求；换曲取消旧请求，迟到结果不进入当前歌曲。
- 已核验时间轴可用时降低 AX 扫描频率。短暂空读取不会立刻清掉新鲜歌词，也不会延长旧句的有效期。
- 重复副歌在句间空拍使用与显示一致的时间规则，避免高亮突然退回普通文字；回拖重新定位对应的重复句。
- AX 暂时没有封面时，仅复用同进程、同曲且经验证的系统封面，避免盲目沿用上一首。
- 暂停后进度跳转若使汽水恢复播放，会在确认同曲、同进程且用户没有发起新的顶屿操作后定向恢复暂停；仍可能有短暂播放，不等于原子暂停跳转。

## 验证与限制

完整 Swift 测试 321 项通过，包括时间轴跨句/回拖、重复副歌、缓存淘汰、多歌手匹配、请求取消、搜索/详情不一致、版本歧义、非有限时长、封面归属和播放控制门禁。Release 构建与安装签名校验通过。

前一轮实机样本中新歌查询约 1.74 秒，缓存曲目从切歌命令完成到歌词状态发布约 0.63 秒。这些是本次设备、歌曲与网络下的样本，不是屏幕首帧测量、声音同步测量或速度承诺。完整全屏/多桌面、断网恢复、汽水端与顶屿同时操作及长期播放仍需扩大验收。

运行时音乐控制使用 PID 绑定的汽水窗口语义控件；不会为了歌词把最小化转换为隐藏，也不会从后台主动弹出汽水窗口。进度跳转需要来源与媒体焦点校验，不满足条件时保持只读。

## 隐私

「显示歌词」默认关闭，开启后搜索请求包含当前歌名和歌手，随后请求匹配歌曲的词级歌词详情。测试用自编合成歌词验证接口逻辑，不提交第三方 App 解包源码、账户数据、音频或个人桌面录屏。
