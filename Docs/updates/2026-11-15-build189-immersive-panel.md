# build 189：沉浸音乐面板

应用版本为 **0.1.4 build 189**，计划作为 v0.1.4-alpha.1 预发布，仍是 Alpha 开发预览。历史 v0.1.3-alpha.2 / build 180 保留。

## 新的展开音乐面板

展开后的音乐面板重新设计，和刘海连成同一块纯黑表面：

- **大封面，单栏歌词。** 左边是 124pt 的封面；右边一栏从上到下是歌名与歌手、当前句、翻译和下一句。当前句放不下时先略微缩小字号，仍放不下才滚动。
- **封面的颜色。** 当前封面经模糊后从面板左侧晕开，向右过渡到纯黑；刘海那一条始终是纯黑。打开“降低透明度”或“增强对比度”时，整个面板保持纯黑。
- **安静的静止状态。** 指针不在面板上时，底部只有一条细进度线；指针移上来，换成上一首、播放 / 暂停、下一首和可拖动的进度条，左边是已播放时间，右边是剩余时间。需要“恢复控制”或打开旁白时，控制行一直显示。
- **尺寸固定。** 面板固定 660 × 190，有没有歌词、歌词来得晚都不改变大小。没有歌词时，歌名和歌手放大到歌词的位置。
- 右上角的歌词开关、展开方式、收起、最小化按钮只在指针位于面板上时出现。

## 修复

- 悬停展开模式下，在面板里点按一下后把鼠标移开，面板现在会照常收起，不用再点一下外部。

## 内部改动

这些改动不改变行为，由测试和状态流重放夹具覆盖：

- `main.swift` 按文件拆分；音乐协调器拆出使用诊断、播放操作跟踪与进度跳转三部分。
- 汽水状态流的重放夹具进入 CI。
- 每首汽水歌曲记录一条匿名的歌词结果分类，只存在本机，不含歌名和歌词，用于判断后台歌词问题。
- 删除早已停用的汽水歌词 OCR 实验代码。

控制仍只发送给已适配并经过核验的来源，不发送全局媒体键，也不会为了读取歌词自动打开、显示或取消最小化汽水。
