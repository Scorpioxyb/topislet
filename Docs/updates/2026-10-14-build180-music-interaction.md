# build 180：展开方式与歌词快捷切换

2026-10-14 源码更新。应用版本为 0.1.3 build 180，仍处于开发预览阶段。本次不发布新的下载包：公开预发布版保持 v0.1.3-alpha.1 / build 148。

## 音乐面板更可控

展开面板右上方增加歌词按钮和展开方式菜单。也可以右键音乐岛，或在设置的“音乐面板”中调整；选择会保存。

| 展开方式 | 行为 |
| --- | --- |
| 悬停展开（默认） | 鼠标移入时展开，移开后收起；操作播放控件后保留面板 |
| 点击展开 | 鼠标经过不打开，点击折叠音乐岛一次直接展开 |
| 保持展开 | 音乐成为主活动时展开，鼠标离开或点击其他窗口仍保持；可随时手动收起 |

保持展开不抢占计时器、提醒或用户已经展开的活动中心，仍遵守全屏隐藏。手动收起后，常规歌词刷新和同一音乐会话内的切歌不会重新撑开面板。

歌词开关现在只决定阅读区是否显示，不再顺带改变展开状态。关闭歌词仍保留播放控制与进度条；开启后显示当前来源能够提供且通过核验的歌词。旧的“歌词更新时自动展开”设置会迁移到“保持展开”；用户选过新方式后，以新选择为准。

## 这次同步的稳定性改动

- 有歌词与无歌词共用同一播放控制及时间轴视图，减少内容变化时的重建。
- 汽水元数据扫描与语义控制分队列执行，避免慢读取阻塞按键；缓存控件仍核验当前唯一控件组、排列及身份。
- 延迟元数据、歌词、进度回读绑定当前曲目、PID 与会话，避免旧结果覆盖新歌。
- 元数据等待期间，如果近期已核验的同 PID 播放状态与已发布基准一致，可以继续保留播放显示；明确暂停、未知或过期证据不能借此保留旧播放状态。该规则不能授权跨曲歌词或跳转。
- 提醒排队和恢复使用独立活动策略；用户在途控制和已经展开的活动中心保持优先。
- 保留远端已有的异步测试同步门闩，不依赖固定睡眠时间保证事件先后。

控制仍只发送给已适配且经过核验的来源，不发送全局媒体键，也不为了读取歌词自动打开、隐藏或取消最小化汽水。
