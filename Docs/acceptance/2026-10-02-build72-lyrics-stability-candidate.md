# build72 歌词稳定性候选

状态：本地 Release 候选，Goal 继续进行；未封版、未发布。

## 已修复

- `QishuiLyricReader` 的 AX 兜底按请求曲名/歌手筛选，并复用统一曲目一致性策略，避免多艺人分隔符差异导致有效歌词被拒。
- `MediaAdapter` 不再在歌词 reader 返回空结果后另建 AX reader 扫描同一汽水窗口。
- 桌面歌词仅接受唯一 `active` 段落，且文本必须属于同歌曲已验证歌词集合；active 行不唯一或身份不匹配时不发布歌词。
- 移除没有 active 行语义的通用 AX/页面歌词回退，避免可信歌词快照尚未到达时拿附近旧句填充。
- 清理作词、作曲、编曲等元数据行，避免制作信息进入歌词显示。
- marquee 换文本时保留测得内容宽度，避免尺寸偏好没有变化时宽度留在零值、长句不启动滚动。
- 紧凑态采用不对称 280pt 歌词翼 + 96pt 控制翼，并将溢出滚动提高至 54pt/s，避免右侧留白挤占歌词可读宽度。
- 产品方案统一为超长句滚动、稳定字号及可信当前行优先。
