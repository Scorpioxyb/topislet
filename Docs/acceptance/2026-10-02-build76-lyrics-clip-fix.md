# build76 紧凑歌词裁切修复

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 问题证据

当前顶屿紧凑窗口为约 33pt 高的附着顶栏。原布局把 18pt 主歌词、13pt 副行和 1pt 间距直接贴合在顶栏内；字体实际字形的上下溢出没有安全余量，导致主句顶端缺字、译文贴近底部并在窗口边界处被裁切。用户提供的截图和本轮只读 Computer Use 截图均复现该现象。

## 修复

- 紧凑歌词改用 28pt 内容框：主句 16pt 行高、副句 12pt 行高，间距为 0。
- 内容框在 33pt 顶栏内居中，上下各保留 2.5pt 安全边距，避免附着窗口的裁剪边界吞掉字形。
- 保留 build75 的文本绑定测量：切句时先清除旧句宽度和偏移，等新句测量完成后再滚动。
- 保留 80–200pt/s 的按溢出宽度滚动策略；短句不滚动。
