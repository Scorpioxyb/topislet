# build180：音乐展开方式与歌词快捷切换

2026-10-13。用户已解锁，并明确要求先开发功能、减少测试；从下一项选择中指定“音乐交互：展开方式与歌词显示切换”。本轮只实现这项功能，不进入文件Shelf、不推送或发布。

## 使用方式

音乐展开面板右上方新增歌词按钮与“…”菜单；右键音乐岛或进入设置→音乐面板也能选择展开方式。偏好持久化。

| 方式 | 行为 |
| --- | --- |
| 悬停展开（默认） | 保留现有鼠标移入展开、移出收起的习惯；操作控件后保留面板 |
| 点击展开 | 鼠标经过不展开；折叠岛点击一次直接展开音乐 |
| 保持展开 | 音乐首次成为主活动时展开，外部点击与鼠标移出不收起；用户仍可手动收起 |

手动收起后，常规歌词刷新和同一音乐会话内切歌不会重新展开；退出后新音乐会话按所选方式进入。保持展开不抢占计时器、提醒或用户打开的活动中心，也不更改全屏抑制。

歌词按钮只切换阅读内容，不再自动打开或收起面板。设置变化会按提交后的偏好重算AppKit窗口尺寸，保留播放控件与进度视图。显示歌词仍使用原来源和身份门禁；未读取到内容时沿用“聆听音乐”。设置页保留开启歌词的网络查询说明。

旧“歌词更新时自动展开”偏好为true、且未选过新模式时迁移为保持展开。旧偏好为false默认悬停。用户选过新模式后以新模式为准，重置恢复悬停与关闭歌词。原自动展开分支已从元数据/歌词刷新路径移除。
