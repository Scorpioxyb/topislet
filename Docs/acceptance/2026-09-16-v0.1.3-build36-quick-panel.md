# v0.1.3 build 36 空岛快捷面板验收

日期：2026-09-16

## 调整目标

build 35 的空岛入口已可使用，但展开面板仍以“活动”作为页面标题，收起后还会停留在写着“活动”的 `377pt` 紧凑横条，视觉层级和占用范围都偏重。本轮将它调整为一次性的快捷面板，而不是独立活动页面。

## 实现

- 删除展开面板中的可见“活动”标题。
- 删除 `CompactActivityCenter` 及写着“活动”的紧凑态内容。
- 顶部改为“专注计时”与单一收起按钮。
- `5/15/25/45` 四个预设显示完整“分”单位。
- 日历和提醒事项保留为两条次级权限/开关行。
- 展开宽度从 `460pt` 收紧为 `420pt`，Body 高度从 `194pt` 收紧为 `168pt`。
- 收起、外部点击和设置中的折叠操作均直接回到空岛。
