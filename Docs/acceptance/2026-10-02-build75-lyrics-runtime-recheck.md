# build75 歌词运行态复核

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 本轮改动

- 每个 marquee 宽度测量现在携带原歌词文本；换句后先禁用旧测量/偏移，等新句宽度到达再决定是否滚动。
- 滚动基准提高到 80pt/s，上限 200pt/s，目标单程时间 0.9 秒，停留时间 0.25 秒。
- 增加回归测试，覆盖旧句测量不得驱动新句位置，以及按溢出宽度提高滚动速度。
