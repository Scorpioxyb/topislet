# Build 151 默认态改良

日期：2026-10-12（America/Los_Angeles）。本地安装候选，不是 GitHub Release。

## 视觉参考与取舍

查看 [NotchNook 官方演示](https://getnotchnook.com/) 和其演示封面。公开材料用于理解刘海处的收纳与低干扰呈现，不证明其内部窗口配置、尺寸或时序。

顶屿沿用自身的物理摄像头几何、系统菜单栏避让与窗口抑制规则。空闲默认态只覆盖摄像头区域；音乐折叠态保留两侧各22pt，左侧用16pt封面替代通用音乐图标，右侧播放时显示已有波形、已确认暂停时显示静态暂停符号。已设置的歌词自动展开偏好没有被覆盖。

冷启动不再因音乐存在自动进入紧凑态；后台音乐首次接管空闲折叠态也保持折叠。用户点击后的歌曲信息、手动展开与已有活动操作继续保留。活动变动导致折叠宽度变化时，AppKit 从提交后的模型刷新几何。

## 真实窗口检查

- 正常安装版空闲窗口从229pt缩到185pt（本机摄像头宽度），实测截图370×70像素，2倍缩放；两侧没有网格图标或假活动波形。
- 空闲岛点击打开活动中心，点击收起按钮能返回最小态。
- 隔离预览以真实应用窗口渲染播放/暂停状态，使用既有QA封面素材；封面与状态符号没有被摄像头或边缘裁切，窗口截图458×70像素。
- 音乐预览点击后进入紧凑信息态。菜单栏上下文截图显示右侧现有系统图标位于岛外；不以此断言所有屏幕、所有图标密度都不会重叠。
- 预览结束后恢复正常模式，运行中主进程为安装路径的一个实例。未改变真实媒体的播放状态；预览不是汽水控制、歌词或延迟验收。
- Computer Use 会话已重置；SkyComputerUseService 已停止，最终进程检查未发现该服务或 CUALockScreenGuardian。
