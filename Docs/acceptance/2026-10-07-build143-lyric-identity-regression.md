# Build 143：歌词身份稳定与切歌实测

## 修改

- 将歌词身份选择整理为 QishuiLyricIdentityPolicy：运行中的汽水 MediaRemote 播放身份优先，缺少有效播放身份才采用运行中的 AX 身份。
- 每次判断只取一份运行进程清单，不再先检查 AX 进程又重复检查播放进程。未测量整体 CPU 降幅。
- 补齐两项回归测试：不同歌手分隔符/推荐歌曲不覆盖播放身份，退出进程不参与选择，真正换曲更新身份。
- 保留 build 142 的内存缓存、即时请求调度、重试退避、多歌手匹配和暂停跳转回读保护。

## 验证

- 新测试在缺少策略实现时构建失败，随后通过；完整 Swift 测试 314 项通过。
- Release 40 个代码/数据段及安装签名校验通过；/Applications/顶屿.app 的版本为 0.1.3 build 143。
- Computer Use 实测 彼岸王国 / 石岩 与 FREAKED OUT / Fat Papi, prodshushy 前后切换；后一首冷请求日志 latency_ms=1740。
- 首次切回缓存曲目：previous 控制结果 00:55:40.691，缓存命中 00:55:41.315，歌词状态发布 00:55:41.316。控制完成到歌词发布约 625 ms，不是点击到屏幕首帧的完整测量。
- 约 3.1 秒内连续下一首、上一首、下一首、上一首，四次控制日志均 accepted；缓存命中并跟随曲目更新。观察中未看到持久串句，但仍有瞬时元数据缺失，不构成所有竞态均通过的保证。
- 实测最终回到彼岸王国，可正常展开并暂停；尝试恢复原进度时 Computer Use 提示用户已改变应用，停止继续覆盖用户操作。
