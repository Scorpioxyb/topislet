# v0.1.3 build 39 汽水控件树恢复验收

日期：2026-09-19

> 历史验收记录：后台自动唤起汽水的策略已于 2026-09-20 撤回。当前仍会检测 `windowClosed`、`controlTreeUnavailable` 和 `unknown` 并安全禁用定向控制，但不会自动打开、取消隐藏或激活汽水音乐；打开外部 App 必须来自用户明确点击“恢复播放控制”。

## 问题

build 38 只在 `windowClosed` 时唤醒汽水。汽水进程仍在、窗口对象仍存在，但 Electron 辅助功能树退化为稀疏根节点时，状态是 `controlTreeUnavailable` 或 `unknown`；此时播放控件保持禁用，手动点开汽水后才恢复。

## 修复

- `windowClosed`、`controlTreeUnavailable` 和 `unknown` 统一进入控件恢复流程。
- 每次恢复先清理顶屿的 AX 控件缓存并取消隐藏汽水，再使用不激活应用的配置唤醒汽水。
- 自动恢复最多尝试三次，避免无限拉起；仍未恢复时显示“恢复播放控制”入口。
- 诊断信息保留最近一次恢复原因、次数和结果，便于间歇故障恢复后追溯。
- 唯一语义播放控件门禁保持不变；没有唯一候选时不发送播放命令。
