# v0.1.2 日常使用日志验收

日期：2026-08-31

## 目标

- 使用日常真实操作数据分析来源切换、控制、seek、切歌 UI 和封面延迟。
- 保持日志低频、仅本机、可聚合，不记录完整音乐内容或账号数据。
- 自动化结果只汇报通过数量与异常。

## 实现

- Unified Logging subsystem：`io.github.scorpioxyb.topislet`。
- 结构化 category：`MusicUsage`，schema 前缀为 `topislet_usage v=1`。
- 曲目只记录来源与 12 位 SHA-256 截断指纹，以及歌手、封面、时长、歌词字段是否齐全。
- 事件覆盖观察启动 / 停止、来源切换原因、播放器进程启动 / 退出、曲目元数据、UI 实际发布、封面到达、播放状态、控制与 seek 结果和耗时。
- `swift run DailyUsageAnalyzer --last 24h` 读取系统日志，聚合来源抖动、成功率及 P50/P95 延迟；报告默认写入 `.build/qa/`，不进入 Git。
