# build81 模式树切换竞态修复

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 新证据

build80 自然收起观察中，窗口几何已经缩回普通档，但旧紧凑态仍短暂显示原文和译文，形成用户此前反馈的黑边/错层观感。`IslandRootView` 原先同时挂载收起、紧凑、展开三个 header，只用 opacity、命中测试和无障碍隐藏切换；AppKit frame 动画先发生时，旧紧凑树可能残留一帧。

## 修复

- 改为对 `model.mode` 做 `switch`，同一时刻只创建一个 header 内容树。
- AppKit 仍负责窗口 frame 动画，但不再让旧 mode 的歌词视图参与缩窄过程。
- 保留 build80 的 0.9 秒歌词快照新鲜度门禁。

## 验证

- build81 Release 安装、自动化测试和自然收起截图：待完成。
- 汽水音乐不点击、不切歌、不控制播放。

## 尚未关闭门禁

- 收起/紧凑/展开连续切换无残影和黑边。
- 同一长句完整滚动周期、当前活动行归属、真实播放延迟。
- 资源占用、多屏、全屏和 Reduce Motion。
