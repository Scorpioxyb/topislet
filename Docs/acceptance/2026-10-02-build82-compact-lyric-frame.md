# build82 紧凑态歌词窄框与双行滚动修复

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 问题证据

用户截图中的黑色顶栏约为 377pt 标准紧凑宽度，但 SwiftUI 已经绘制了双行歌词。结果是歌词内容进入了宽歌词布局，AppKit 外框仍停留在旧窄框内，译文从左侧裁掉，主句和译文也各自按不同滚动时钟移动。该现象属于窗口尺寸动画与歌词视图提交不同步，不足以单独证明汽水歌词数据错配。

## 修复

- 歌词可用性变化时，紧凑态窗口改为在主线程提交后的下一轮以非动画方式原子调整宽度，避免 377pt 外框包住宽歌词内容。
- `MarqueeText` 增加明确的单行、固定行高和中心垂直布局，避免字体基线贴到顶边后被裁切。
- 紧凑态原文与译文共用 `MarqueeClock`，歌词变更时统一重启滚动；两行不再各自漂移。
- 没有译文时不再把歌名和歌手伪装成译文行。
