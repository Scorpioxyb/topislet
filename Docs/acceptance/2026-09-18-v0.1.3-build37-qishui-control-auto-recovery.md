# v0.1.3 build 37 汽水控制自动恢复验收

日期：2026-09-18

> 历史验收记录：自动重建窗口的产品策略已于 2026-09-20 撤回。当前行为是用户关闭汽水窗口后仅安全禁用定向控制，不从后台打开任何外部窗口；只有用户明确点击“恢复播放控制”才会打开汽水音乐。

## 变更

- 汽水主窗口被红色关闭后，顶屿识别 `windowClosed` 并自动请求汽水重建窗口。
- 自动恢复使用不激活应用的打开配置，每次窗口关闭事件只尝试一次，避免重复拉起。
- 恢复期间，展开音乐面板用明确的恢复状态替代三枚不可点击的播放控件。
- 自动恢复失败时保留“恢复播放控制”按钮，用户无需理解辅助功能窗口树。
- 恢复后仍要求唯一、可验证的汽水语义播放控件，不使用全局媒体键或 MediaRemote `send-client`。

## 真实交互验证

1. 初始汽水控制状态为 `available`。
2. 点击汽水主窗口红色关闭按钮。
3. 顶屿自动重建汽水窗口，未要求用户手工查找或恢复窗口。
4. 控制状态自动回到 `available`。
5. 展开顶屿后，上一首、播放、下一首均为可用按钮。
6. 点击播放后按钮切换为暂停；再次点击后恢复原暂停状态。
7. 最后将汽水窗口最小化，控制状态保持 `available`。

## 结论

用户以后误点汽水红色关闭按钮时，顶屿会优先自动恢复专属播放控制；无法自动恢复时，界面提供单一、可执行的恢复入口，不再只显示无法操作的黑色按钮。
