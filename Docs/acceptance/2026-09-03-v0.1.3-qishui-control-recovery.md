# v0.1.3 汽水三键可用性恢复验收

日期：2026-09-03

分支：`codex/v0.1.3-development`

App：`0.1.3 (30)`

## 问题与修复

展开岛显示有效汽水歌曲时，上一首、播放 / 暂停、下一首三个按钮曾被错误标记为禁用，并显示“汽水音乐当前未运行”。根因是 MediaRemote 歌曲状态、汽水 AX 控件可用性和 Bundle ID 进程枚举各自维护运行实例，生命周期竞态可能让其中一条路径短暂写入 `.notRunning`，之后没有随实时歌曲状态恢复。

build 30 做了以下收敛：

- 新增统一汽水进程定位器，优先使用已验证 MediaRemote PID，再通过 `NSRunningApplication(processIdentifier:)` 校验 Bundle ID 和终止状态。
- 汽水状态流、语义 AX 控制器、AX 监听和控件可用性刷新统一使用该定位方式。
- 已验证汽水歌曲状态恢复且控件状态不是 `.available` 时，自动重新触发一次控件可用性检查。
- 多个同 Bundle 实例无法唯一确定时不退回任意进程，继续安全拒绝控制。
