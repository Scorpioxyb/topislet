# v0.1.2-alpha.5 智能专辑色候选验收

日期：2026-09-01

分支：`codex/v0.1.2-stabilization`

App：`0.1.2 (23)`

## 目标

保留现有封面颜色识别准确度，改善强调色在纯黑岛体上的可读性、舒适度和切歌连续性。改动只作用于进度轨与状态波形，不扩散为大面积背景色。

## 实现边界

- 色相仍来自现有 32px CPU 下采样平均值，不恢复 Core Image / Metal 路径，也不增加播放器轮询。
- 将强调色的 sRGB 相对亮度约束在约 `0.20...0.52`：暗色只做最小幅度提亮，过亮色只做等比例压暗，保持原色相关系。
- 灰阶封面使用中性亮灰，不强行染色。
- 当前歌曲封面暂缺时保留上一强调色最多 650ms；封面仍未到达才切换为中性回退。全部音乐来源退出时立即恢复白色默认态。
- 未修改媒体读取、控制派发、seek、来源仲裁、窗口几何和动画时间轴。
