# v0.1.3 build 46 控件健康检查

阶段 0 未完成。

## 诊断与改动

build 45 实测窗口数为 0 但恢复入口缺失。代码核对发现：已可用控件不再执行定期健康检查，主要依赖 AX 结构通知；观察器重启重绑间隔及通知防抖可能造成事件漏检。此为代码支持的解释，未运行事件注入证明它是唯一原因。

现在实时观察期间，已可用的汽水控制每至少 2 秒通过现有串行队列重新验证，已有探测进行时不提交重复健康检查；不可用状态继续沿用既有退避重试。检查不显示汽水窗口、不发送媒体按键，结果变化经既有状态发布路径更新。停止观察及重启清除检查时间。
