# 2026-07-22 v0.1.2 多显示器与动画锚定验收

## 目标

关闭双屏环境下展开或收回时岛从内屏迁移到外接屏的问题，并确保悬停、持续展开、移出收回和动画中途反向切换仍保持单窗口、同一顶边和同一水平锚点。

## 根因与修复

旧实现会在每次形态变化和动画纠偏时重新读取 `NSScreen.main`。鼠标或焦点使主显示器临时变化后，动画目标从内屏中心 `855.5pt` 跳到外接屏中心 `2990pt`，最大水平漂移达到 `2134.5pt`。

现实现为 App 生命周期维护稳定目标显示器身份：

- 首次选择优先使用带摄像头模组的内建屏幕。
- 绑定显示器仍存在时，`NSScreen.main` 变化不改变目标。
- 展开、收回、非动画重排和动画逐帧纠偏统一使用同一目标屏幕。
- 只有绑定屏幕消失时才重新选择，优先回退到带摄像头模组的屏幕，其次为当前主屏和首个可用屏幕。
- CGEvent 外部点击不再借用临时主屏转换坐标，避免双屏排列下误判。
