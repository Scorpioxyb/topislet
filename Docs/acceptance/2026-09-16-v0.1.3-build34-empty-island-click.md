# v0.1.3 build 34 空岛点击验收

日期：2026-09-16

## 问题

未运行汽水音乐且没有其他真实活动时，点击折叠岛仍会请求紧凑音乐态。安装版实测窗口从 `245×35pt` 瞬间拉宽到最高 `357×35pt`，随后回落，形成空内容闪动和回弹。

## 修复

- 点击和悬停共用同一真实活动展开门禁。
- 音乐态只有存在当前歌曲时允许展开。
- 计时器活动始终允许展开。
- 提醒态只有存在待展示提醒时允许展开。
- 空岛点击保持折叠，不生成无内容的紧凑态动画。

## 安装版验证

- App：`0.1.3 (34)`，严格签名通过。
- 空状态点击后连续 20 个样本、覆盖 `0–380ms`，窗口始终为 `245×35pt`、`Y=-1`，没有拉宽中间帧。
- 计时器折叠态点击反向回归：窗口连续展开到 `420×189pt`，顶部最终回到 `Y=-1`。
- 预览进程结束后已恢复单一安装版主进程和两个预期只读音乐状态流。
- `swift test --quiet`：233 项通过。

## 范围

本轮只改变无真实活动时的折叠岛点击行为，不改变音乐同步、控制、进度、活动优先级或悬停动画参数。
