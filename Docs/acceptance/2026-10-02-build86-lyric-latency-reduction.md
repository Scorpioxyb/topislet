# build86 歌词发布节拍与延迟修复

日期：2026-10-02

## 变更

`IslandModel` 的媒体提交节拍从 500ms 调整为 250ms。汽水歌词 AX 读取本来就以 250ms 为最小间隔；此前主模型每 500ms 才提交一次，导致新 active 行通常额外等待半秒。媒体源刷新、播放位置刷新仍由 `MusicAdapterCoordinator` 的独立节流控制。
