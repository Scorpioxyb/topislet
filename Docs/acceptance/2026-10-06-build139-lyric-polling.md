# Build 139：歌词后台读取优化

## 变更

- 仅在同曲、时间轴非空、MediaRemote 身份匹配且存在播放位置时，将 AX 歌词读取间隔由 0.18 秒改为 2 秒。没有可靠时间轴时继续使用 0.18 秒间隔。
- 时间轴已经负责展示时，AX 行变化不再额外触发一次整岛状态发布；正常实时状态发布仍保留。
- 单次 AX 空结果可保留同曲的上一帧，但沿用原始 checkedAt，仍受 0.72 秒有效期限制。换曲或超时不保留。

## 验证

- 新增 3 项策略测试；首次测试因策略未实现而构建失败，实现后通过。
- 完整 Swift 测试：307 项通过。
- Release 二进制 40 个代码/数据段校验通过，安装包和 /Applications/顶屿.app 签名校验通过。
- 安装版本：0.1.3 build 139。
- Computer Use 实测歌曲 Kinda Do / 蓝爵醺调：折叠态点击展开，暂停后按钮变成播放且时间保持；拖动 35% 与 55% 后时间与歌词均定位到目标区间，恢复播放后歌词继续切换。

## 未关闭的问题

- 两次实测均发现：暂停后进度跳转，汽水会随后恢复播放。MediaAdapter 这条路径没有主动发送播放命令，仍须确认下游 seek 的行为并解决暂停保持问题。不能据此声称播放控制全部稳定。
- 未做同状态 CPU 对照或声画时间差测量；读取间隔降低不等于已证明整体 CPU 降幅或延迟改善。
- 未验证断网恢复、多歌曲快速切换、全屏/多桌面或长期播放；未发布新 GitHub Release。
