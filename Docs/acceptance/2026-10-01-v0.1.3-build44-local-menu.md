# v0.1.3 build 44 本体菜单与生命周期

阶段 0 仍未封版。build 43 的音乐恢复、后台三键和百度全屏证据属于历史版本，不能直接替代 build 44 的全部回归。

## 改动

原有设置和退出入口集中在菜单栏状态项；岛本体没有直接入口，实机 Computer Use 的菜单栏聚焦与 Command-Q 未能退出顶屿。为便于用户在状态图标不易找到时自行操作，在岛本体增加右键菜单“设置…”及“退出顶屿”，两项直接调用既有 AppDelegate 的设置与正常终止流程。闭包弱引用 AppDelegate，保留原有菜单栏入口。

## 验证

- 完整测试 251 项通过，汽水控制安全脚本和 diff 检查通过。
- Release 构建、打包、安装 build 44，安装版签名验证通过。替换产物按既有脚本移入废纸篓。
- 通过 Computer Use 冷启动安装版，右键点击折叠入口，AX 显示两个菜单项。
- 选择“设置…”并按 Return，真实打开“顶屿设置”窗口，常规、音乐、活动、布局、关于标签可见；未更改设置。
- 关闭设置窗口返回折叠岛，再通过右键菜单选择“退出顶屿”并按 Return；随后进程检查无 `MacBookIsland` 主进程。本次为正常菜单终止，不是 TERM 信号验收。
- 再通过 Computer Use 启动安装版，独立检查 `instances=1 / visibleWindows=1`，PID `32004`，窗口 `245×35, x=732, y=-1`。
- 本轮结束 reset Computer Use 并清理辅助进程，顶屿保留运行。

菜单打开、设置关闭、退出及重开路径已实测；尚未测试在设置窗口打开且恢复任务进行时退出等组合情形。剩余阶段 0 门槛继续保留：异常 AX 恢复时间与反馈、跨桌面与独立伪全屏、其他播放器、80ms 反向及逐帧黑边，以及 build 44 相应回归。
