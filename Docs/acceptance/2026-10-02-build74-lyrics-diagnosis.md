# build74 歌词诊断与修复

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 本轮结论

“歌词不匹配、长句像不滚、紧凑态裁切、更新时有负担”不是单一视觉问题。代码中存在一个歌词归属漏洞、一处过密 AX 树发现，以及紧凑态文本总高度超过实际顶部栏的布局错误。

## 已修复

- 主播放器的唯一 `active` 段落此前只要求曲名/歌手匹配和歌词全集已验证，却没有要求当前 `active` 文本也属于该曲目语料；现在主播放器和桌面歌词共用唯一活动段落与歌词语料校验，不一致时回退为空。
- 桌面歌词此前每次读取都遍历桌面歌词树并重新找全部段落；现在节点发现按 3 秒节流并复用段落引用，活动行仍按既有 250ms 节奏读取，昂贵发现放在主播放器采样之后。
- 紧凑态原两行高度合计 36pt，而顶部栏为 33pt，导致译文天然被裁；现调整为 18pt + 1pt 间距 + 13pt，总计 32pt。
- 有歌词时紧凑态左翼从 280pt 加宽至 320pt；Marquee 从固定 54pt/s 调为 72-112pt/s，长句更快覆盖溢出部分，速度有上限。

## 未关闭门禁

- 实机曲目在连续观察中自然变化，因此没有得到稳定同一曲目的逐帧身份/歌词活动行比对；未通过自动切歌制造条件。
- 未观察一条稳定长句完成首尾完整滚动；当前速度变化有单元测试，但没有对应的实机时序记录。
- 未测量切句延迟、AX 耗时、CPU 或内存；不能声称延迟或性能已经解决。
- 未完成有歌词/无歌词、紧凑/收起/展开、全屏、多屏、黑边和 Reduce Motion 的完整安装版截图矩阵。
- Computer Use 画面只在本轮临时观察，没有持久化截图附件；本记录不是带图的 UX 审计报告。

结论：build74 修复了代码可证实的错误归属路径、重复 AX 子树发现和紧凑态文字被垂直裁切的问题；P1 的真实歌词同步、长句完整滚动与时延门禁仍开放，不能宣称歌词功能已验收。
