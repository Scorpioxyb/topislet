# v0.1.3 build 33 macOS 27 活动入口验收

日期：2026-09-16

## 结论

顶屿在 macOS 27.0 上完成第一轮功能扩展。音乐链路保持不变，专注计时从隐藏的固定 25 分钟能力升级为菜单栏与设置中的可发现入口，可选择 `5/15/25/45` 分钟；日历和提醒事项继续通过 EventKit 在用户授权后短暂接管顶屿，并在结束后恢复音乐或仍在运行的计时器。

## 环境

- 系统：macOS `27.0 (26A428)`
- 架构：Apple Silicon arm64
- App：`0.1.3 (33)`
- 安装路径：`/Applications/顶屿.app`
- 最低系统版本仍为 macOS 26.0

## 功能验证

- 菜单栏“开始专注计时”提供 `5/15/25/45` 分钟四个预设。
- 设置页“日程”更名为“活动”，使用分段选择器选择专注时长并直接启动。
- 用户主动启动计时时会取消当前提醒展示，防止旧自动关闭回调把新计时错误切回音乐。
- 提醒结束后只在原活动是计时器且计时仍运行时恢复计时，否则回到音乐。
- 计时器展开态为单窗口 `420×189pt`，WindowServer 顶边 `Y=-1`；文字、进度轨和控制按钮无截断或重叠。
- 安装版恢复为单一主进程，并保持汽水与网易云两个预期只读状态流。

- 专注计时不需要额外权限。
- 日历和提醒事项继续由用户分别授权，顶屿不读取其他 App 的系统通知。
- 本轮没有改变辅助功能、Apple Music 自动化或 MediaRemote 的权限范围。
