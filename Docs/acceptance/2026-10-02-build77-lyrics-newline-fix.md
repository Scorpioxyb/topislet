# build77 收起态歌词换行修复

状态：本地 Release 候选，Goal 仍进行中；未封版、未发布。

## 新证据

build76 安装后的自然播放观察捕获到：汽水当前歌曲的 AX 歌词包含原文和中文译文，顶屿辅助功能标签也返回同一对文本；但顶屿截图呈现为原文贴顶、译文贴底，和用户提供的截图一致。此时窗口是收起态，不是 build76 已修复的紧凑宽档。根因是某些汽水 AX 静态文本节点把原文和译文作为一个带嵌入换行的字符串返回，清洗层没有先拆行。

## 修复

- `MusicLyricPresentation.clean` 现在先按换行展开每个 AX 文本值，再进行占位符、元数据和诊断行过滤。
- 收起态因此只取当前配对的主句，不会把原文和译文作为一条字符串在 33pt 顶栏内换成两行。
- 紧凑态继续使用 build76 的 28pt 内容框和上下 2.5pt 安全边距，译文仍作为第二行显示。
- 新增测试覆盖 `\n`、`\r\n` 嵌入文本及中英配对结果。
- 后续状态机收敛将无歌词、当前句和当前句译文统一为 `MusicLyricPresentationState`，所有显示状态共享同一对文本。
