# Build 148：汽水进度跳转后继续播放

日期：2026-10-08（America/Los_Angeles）

## 修复

用户希望点击/拖动进度条即跳转并播放。旧版本会在暂停跳转后观察到汽水开始播放，再发送暂停以保留旧暂停状态，导致短暂播放后停止。删除该反向暂停逻辑，改为确认同曲仍暂停时才补发播放；已播放或未知状态不盲切。保留歌曲、来源、PID、操作代次及后续手动控制的失效保护。

本次定向修复汽水路径，未改变 Apple Music 进度控制。
