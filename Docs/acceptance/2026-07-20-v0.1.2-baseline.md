## 新增矩阵

- 三个已适配 Bundle ID 与未知来源关闭失败。
- 三来源同时播放时逐一以前台来源覆盖后台优先级。
- 汽水与网易云后台开始播放时分别遵守自己的稳定延迟。
- 待切来源变化后，旧候选不得迟到提交。
- 当前来源恢复播放后取消旧待切计时。
- 全部来源退出后清空选择并递增代次。
- 同来源刷新不递增代次，切走再切回必须创建新代次。
- 缓存汽水不能压过真实播放的网易云。
- 三个前台来源无歌曲时仍保持应用身份，后台无歌曲时不创建虚假来源。
- 三来源暂停时保持当前网易云。
- 三来源控制授权均要求显示来源与选择一致，且不能跨代次复用。
